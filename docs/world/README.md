# World Bible

The Socarengue world bible defines the mythology, symbolic language, character architecture, resonance logic, and soundtrack philosophy behind the platform.

This section is not implementation documentation. It is the creative canon layer that should inform product structure, visual design, content modeling, and audience experience.

## Files

- [mythology.md](./mythology.md): central mythic premise, emotional inheritance, city memory, and archive logic
- [characters.md](./characters.md): character role system and dossier philosophy
- [resonance-rules.md](./resonance-rules.md): rules for music, memory, frequency, objects, and emotional power
- [visual-symbolism.md](./visual-symbolism.md): recurring symbols, textures, color logic, and visual motifs
- [soundtrack-philosophy.md](./soundtrack-philosophy.md): music as story engine, reader experience, and archive artifact

## Guiding Principle

Socarengue should feel like a world discovered through fragments: songs, city traces, inherited memories, symbolic objects, visual signals, private notes, public transmissions, and emotional frequencies.

The platform should never explain away all mystery. It should give creators enough structure to build coherently while giving the audience enough absence to keep wondering.
