# Characters

Characters in Socarengue should feel like carriers of rhythm, memory, desire, inheritance, and unresolved signal.

They are not only profiles or cast entries. They are living nodes in the mythology.

## Character Philosophy

Every major character should connect to at least one of the following:

- inherited rhythm
- emotional memory
- city memory
- musical power
- symbolic object
- family or community legacy
- hidden resonance
- unresolved loss, longing, devotion, or betrayal

Characters should be written with mystery, but not emptiness. The audience should sense depth before receiving explanation.

## Character Dossier Structure

Future character dossiers should support:

- name
- aliases
- public description
- private creator notes
- visual references
- emotional frequency
- musical association
- symbolic objects
- relationships
- first appearance
- issue appearances
- lore links
- soundtrack links
- archive artifacts
- secrets known only to creators

## Character Role Types

Possible character functions:

- **Carrier:** holds inherited rhythm or emotional memory.
- **Listener:** perceives hidden resonance before others do.
- **Amplifier:** intensifies emotional frequencies around them.
- **Keeper:** protects objects, songs, histories, or rituals.
- **Breaker:** disrupts inherited patterns.
- **Witness:** records what others deny or forget.
- **Translator:** interprets symbols, music, or archive fragments.
- **Haunted:** lives under the pressure of unresolved transmissions.

These are creative lenses, not rigid classes.

## Relationship Logic

Relationships should carry emotional charge.

Track:

- loyalty
- betrayal
- inheritance
- desire
- rivalry
- protection
- silence
- debt
- shared song
- shared object
- shared place
- secret knowledge

The best relationship links should imply story, not merely categorize it.

## Public vs Private Character Knowledge

Audience-facing character pages should preserve mystery.

Public dossiers may include:

- visible role in the story
- known affiliations
- symbolic associations
- issue appearances
- public artifacts
- soundtrack links

Private studio dossiers may include:

- unrevealed history
- continuity notes
- future arc
- hidden relationships
- resonance abilities
- visual generation prompts
- production notes

The system should prevent private character truth from leaking into public archive surfaces before it is narratively earned.
